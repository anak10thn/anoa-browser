## 2026-05-27 — task-006: Implement GET /render/stream.mjpeg MJPEG stream endpoint

- For long-lived streaming responses, do NOT call `disconnectFromHost()`/`deleteLater()` at the end of the route handler — just return, leaving the socket open.
- Parent the `QTimer` to the socket (`new QTimer(socket)`) so it is automatically destroyed if the socket is deleted by any path, preventing dangling timer callbacks.
- Use `socket` (not `this`/HttpServer) as the context object in `QTimer::timeout` lambda connections — the connection is then auto-disconnected when the socket is destroyed, eliminating any use-after-free risk.
- Capture `m_browser` as a local `AnoaBrowser *browser` before the lambda to avoid capturing `this` in a lambda whose lifetime may exceed the HttpServer's. Raw pointer capture is safe here because AnoaBrowser outlives all sockets.
- The `disconnected` signal handler must call `frameTimer->stop()` BEFORE `socket->deleteLater()` — stopping first prevents a queued timeout firing on a socket in the process of deletion.
- `QPixmap::save(QIODevice*, "JPEG", quality)` takes quality 0–100; passing 70 as the third argument produces JPEG quality 70 without needing a separate encoder setup.
- The 512 KB back-pressure check (`socket->bytesToWrite() > 512*1024`) should run before any capture work — fail fast before calling `grab()`.

## 2026-05-27 — task-002: Implement GET /render/screenshot.png endpoint

- The .h only forward-declares `AnoaBrowser`; the .cpp must `#include "browser/anoa_browser.h"` to call any member functions (including inherited `QWidget::grab()`).
- `QWidget::grab()` runs synchronously on the Qt main thread (the slot is already on the main thread) — no QEventLoop bridging needed for the PNG capture path.
- The existing `sendResponse` helper hardcodes `Content-Type: application/json`; non-JSON responses (PNG, plain-text errors) must build and write their own response bytes inline.
- Inline response building pattern: construct `QByteArray` header string, then `+=` the binary body — avoids a separate helper while keeping binary safety.

## 2026-05-27 — task-003: Implement GET /render/html endpoint

- `QWebEnginePage::toHtml()` is callback-based (async); bridge to synchronous HTTP using a local `QEventLoop` — call `loop.exec()` after `toHtml()`, quit from inside the lambda.
- Default `timedOut = true` pattern is cleaner than a separate flag: the lambda flips it to false and calls `loop.quit()`; the timer just calls `loop.quit()` without touching the flag. After `loop.exec()` returns, a single `if (timedOut)` branch handles both real timeouts and null-browser cases.
- `AnoaBrowser` inherits `QWebEngineView::page()` — no extra accessor needed; just call `m_browser->page()->toHtml(...)` directly in `http_server.cpp`.

## 2026-05-27 — task-004: Implement POST /render/navigate endpoint

- `QUrl::isRelative()` is the right check for "absolute URL" — an empty or path-only string parses as valid but relative; combine `isValid() && !isRelative()` to catch both cases.
- Body-reading pattern for POST: slice `requestData.mid(headerEnd + 4)`, then loop `socket->waitForReadyRead` only if `Content-Length` says more bytes are coming — avoids blocking on requests without a body.
- `AnoaBrowser` inherits `QWebEngineView::load(QUrl)` directly — no wrapper method needed; call `m_browser->load(parsedUrl)` in `http_server.cpp`.

## 2026-05-27 — task-005: Implement GET /render live viewer HTML page

- Place the `/render/` trailing-slash redirect AFTER the auth check (so unauthorized requests still get 401, not a 301) but BEFORE the global trailing-slash strip (lines 125-126) — otherwise `path` is already `/render` by the time you check.
- Use `url.query()` (not `query.toString()`) to preserve the original query string in the redirect Location header, including the `?token=` param if it was present.
- Embed the HTML as a `static const char htmlTmpl[] = R"(...)"` raw string literal with a single `%1` placeholder; use `QString::fromUtf8(htmlTmpl).arg(screenshotUrl).toUtf8()` to inject the dynamic screenshot URL — avoids complex string concatenation.
- `QString::arg()` is safe here because the HTML template contains no other `%` characters; but would need escaping (`%%`) if template ever gains CSS percentages.
- For the `<img>` src cache-buster, use `src.indexOf("?")>=0?"&":"?"` so the separator is correct whether or not the screenshot URL already has query params (it will when auth token is appended).
